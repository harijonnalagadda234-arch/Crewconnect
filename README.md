# CrewConnect

CrewConnect is a Django-based HR and Employee Management System designed to simplify and manage important HR activities in an organization.

## Features

- Employee Management
- Department Management
- Designation Management
- Employee Attendance
- Leave Management
- Payroll Management
- Payslip Management
- HR Dashboard
- Employee Information Management

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Django ORM

## Project Structure

The project is developed using Django with separate modules for managing HR and employee-related operations.
